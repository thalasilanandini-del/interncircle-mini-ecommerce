# BloomCart - Mini E-Commerce App

An interactive beginner-friendly mini e-commerce application developed as part of my InternCircle Web Development Internship.

## About the Project

BloomCart is a responsive shopping application where users can browse products, add items to a shopping cart, manage quantities, view the total price, and preview their order through an interactive checkout modal.

Product information is stored as JavaScript objects and rendered dynamically on the webpage.

## Features

- Dynamic product rendering from JavaScript objects
- Six different products with categories and prices
- Add products to shopping cart
- Cart item count
- Increase and decrease product quantities
- Remove products from cart
- Automatic total price calculation
- Empty cart state
- Interactive checkout modal
- Order preview before checkout
- Place order interaction
- Responsive design for desktop, tablet and mobile
- Smooth scrolling navigation
- Hover effects and modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Arrays and Objects
- Event Listeners
- CSS Grid
- CSS Flexbox
- Responsive Design
